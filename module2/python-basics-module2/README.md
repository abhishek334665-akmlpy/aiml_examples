# Python Basics — Module 2

A self-contained Jupyter Notebook containing Python programming examples and exercises.

## Contents

The notebook follows the concepts demonstrated in the included examples. It is intentionally kept as a practical code notebook rather than a formal tutorial.

## Requirements

- Python 3.10 or newer
- Jupyter Notebook or JupyterLab

Install the notebook environment with:

```bash
python -m pip install -r requirements.txt
```

## Run

```bash
jupyter notebook
```

Open `python_module2.ipynb` and run the cells as needed.
