# Python Basics

A compact Jupyter Notebook covering fundamental Python programming concepts through small, self-contained examples.

## Topics

- Variables and basic data types
- Arithmetic operators
- Strings and string operations
- Comparisons and conditional statements
- Lists
- Tuples
- Sets
- Dictionaries
- `for` loops and `range()`
- `break` and `continue`
- Functions
- Default arguments
- Returning multiple values
- Variable-length arguments (`*args` and `**kwargs`)
- Lambda functions with `map()`

## Requirements

- Python 3.10 or newer
- Jupyter Notebook or JupyterLab

Install the dependencies with:

```bash
python -m pip install -r requirements.txt
```

## Run

Start Jupyter:

```bash
jupyter notebook
```

Then open `python_basics.ipynb`.

The notebook uses only Python's standard library; Jupyter is included in `requirements.txt` for running the notebook.
