# Python Basics — Module 3 Exercise 4

A self-contained Jupyter Notebook containing Python examples for the concepts demonstrated in this exercise.

## Requirements

- Python 3.10 or newer
- Jupyter Notebook or JupyterLab

Install the notebook environment with:

```bash
python -m pip install -r requirements.txt
```

## Run

```bash
jupyter notebook
```

Open `python_module3_ex4.ipynb` and run the cells as needed.
